# TALENTLENS

AI-Powered Resume Grader & Candidate Screening Tool

Python
MIT License
AI / NLP
Open Source
TalentLens is an intelligent resume grading system that uses AI to evaluate, score, and rank resumes against a given job description — helping recruiters and hiring teams make faster, data-driven decisions.

✨ Features

📄 Resume Parsing

Extracts skills, experience & education from PDF/DOCX

🎯 JD Matching

Scores resumes against job description requirements

📊 Smart Ranking

Ranks candidates by fit score with detailed breakdown

💡 AI Feedback

Gives actionable improvement suggestions per resume

🚀 Quick Start

git clone https://github.com/ashu011-code/TALENTLENS/blob/main/main.py
cd talentlens
pip install -r requirements.txt
python app.py --resume resume.pdf --jd job_description.txt
🛠 Tech Stack

talentlens/
├── parser/        # Resume & JD parsing logic
├── grader/        # Scoring and ranking engine
├── models/        # AI prompt templates & model config
├── api/           # FastAPI backend
├── ui/            # Streamlit frontend
└── data/          # Sample resumes and JDs
